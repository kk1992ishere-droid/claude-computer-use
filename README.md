# turn-anything-cu

让你的 AI 看屏幕、点击、输入，在 Mac 应用之间完成任务。
Let your AI see, click, and type across Mac apps.

## 中文

把 Mac 上已有的 Computer Use 接给你的 AI，用来查网页、填写表单、整理笔记。

先在 ChatGPT/Codex 中启用 Computer Use，使用一次并完成系统授权。然后把这句话发给你的 AI：

```text
帮我安装 https://github.com/kk1992ishere-droid/turn-anything-cu，先阅读仓库的 SKILL.md，再按我当前使用的 AI 客户端完成配置和验证，保留正常授权提示。
```

## English

Connect the Computer Use component already installed on your Mac to your AI for tasks like browsing, filling forms, and organizing notes.

First enable Computer Use in ChatGPT/Codex, use it once, and grant the requested macOS permissions. Then send your AI this:

```text
Install https://github.com/kk1992ishere-droid/turn-anything-cu for me: read the repository's SKILL.md, configure it for the AI client I'm using, and verify the setup while keeping normal approval prompts.
```
